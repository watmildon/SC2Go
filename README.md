SC2Go is a fork of the popular Android application StreetComplete with a focus on getting it up and rolling on iOS. I fully expect the main StreetComplete team to wrap up their porting work (probably more robustly!) and I can shut this all down. They are welcome to use what's here but that's up to them.

In the few cases where there's an upstream issue impacting iOS and Android (that I have needed to resolve to get the port going), I will file issues with the SC team.

This is a silly "on a lark" project that I kinda thought wasn't going to work but here we are.

## Caveats

What this fork is:
* A fast a dirty implementation of the last blocking sets of things to get running on iOS
* Verified to not corrupt OSM data after rounds of internal testing

What this fork isn't:
* a hard fork of SC or any real attempt to engineer for maintainability or even high levels of stability

Things that work:
* Quests
* Overlays
* Localization

Things that don't:
* Let me know! Maybe I will fix them, maybe I will have wandered off to another mapping nonsense.
